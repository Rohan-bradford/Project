# Enterprise Pro Project

P4. Database Management System for Historical
Records
This project involves the creation of a database management system to store and retrieve
research material held in more than one location, making it accessible and visible to
researchers and historians.
The project requires an HTML/CSS application with two SQL databases that are accessible
through a web browser. Some text elements will require hyperlinks to an Images folder.
Several additional projects will also need to be adapted to use this application. Once the
initial design is confirmed to be functional, the completed project will require modifications
to headers so that the design can be reused for multiple projects. The process for making
these changes must be clearly documented in an instruction manual.
Aim of the Project
 The aim of the project is to create two searchable SQL databases to store
information on Staff who worked at the school and Sources that are available for
viewing within the application
 The application is required to automatically open to Page 1 in a browser each time
it is installed or launched.
 A total of 25 pages are required.
 Some text and page numbers within tables must be linked via hyperlinks to the
appropriate sections of the Images folder.
 The Images folder must be subdivided into several sections for efficiency, for
example: Books, Documents, Images, Logbooks, etc.
 All HTML and CSS code must include line numbers and be clearly annotated to allow
easy adaptation for other projects. This documentation must be included in the
instruction manual.
 An instruction manual is required to explain where and how headers and code can
be safely modified to adapt the completed project for use in other applications.
